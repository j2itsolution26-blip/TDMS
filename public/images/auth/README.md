# Login page brand assets

Drop these four files in this folder with these exact names. The login page
already looks for them and falls back to a plain gradient/icon if a file is
missing, so nothing breaks in the meantime — but the real photos/logo need to
land here to match the approved design.

| Filename                   | Content                                                          |
|-----------------------------|-------------------------------------------------------------------|
| `campus.jpg`                | Asian College campus/building photo (hero background)             |
| `logo.png`                  | Asian College Diploma Program Department logo (transparent bg)    |
| `hospitality-student.jpg`   | Hospitality Technology student photo                              |
| `it-student.jpg`            | Information Technology student photo (computer lab)               |
